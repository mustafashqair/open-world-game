# v50g4-2 texture build

LOW/very-low only. Disable with `?v50g4t=0` or `?v50g4=0` and reload.

No KTX2 encoder is installed in the sandbox; this patch deliberately ships an empty
manifest, not fake compressed files. The loader uses original WebP until real assets
are built. It also falls back to WebP on fetch/transcode errors. It preserves callers'
texture transforms, wrapping, filters and color-space choices. Basis transcoder files
already exist in vendor/three170/examples/jsm/libs/basis/.

Install [KTX-Software 4.x](https://github.com/KhronosGroup/KTX-Software/releases)
with `toktx` on PATH. From the repository root run:

```sh
python3 tools/join_large_files.py
python3 -m pip install Pillow
python3 tools/build_v50g4_textures.py
python3 -m http.server 8000
```

The script writes genuine UASTC + Zstd KTX2 with mipmaps, max edge 512 on LOW,
256 on very-low. It uses lower-left row orientation to match external TextureLoader UVs, linear normal maps, sRGB color maps and excludes HIGH
`-hq` assets. It includes large external city, village/v4 and landmarks textures,
including the original 4096x4096 gravel. Existing `-l` files get their own variants.
Only successful completion publishes the manifest. Commit `v50g4/textures/` and
`v50g4/textures-manifest.json` together. Inspect `window.__g4Textures.compressed`
while visiting village/city/landmarks; force a missing file to check WebP fallback.

Embedded GLB images are not converted by this script. Their runtime caps remain
unchanged. Compare normals/mip seams/texture appearance on target hardware before
publishing. No compression savings are claimed until the generated assets ship.
MEDIUM/HIGH never request the manifest or compressed files.
